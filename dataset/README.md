# Dataset Scabies pada Sapi

Dataset digunakan untuk pelatihan model machine learning pada sistem diagnosa penyakit scabies pada sapi.

## 🔗 Link Dataset
https://drive.google.com/drive/folders/1W9FZN8_BhVy-JNbERFUGsiSZoXmGfA9x?usp=sharing

## Keterangan
Dataset berisi:
- gambar sapi sehat
- gambar sapi terinfeksi scabies
- data non-sapi untuk validasi model

Dataset tidak disimpan langsung di repository karena ukuran file yang besar.
