# Dataset Lumpy Skin Disease

Dataset digunakan untuk pelatihan model deteksi penyakit Lumpy Skin Disease pada sapi.

## Link Dataset

[Download Dataset](https://drive.google.com/drive/folders/1W9FZN8_BhVy-JNbERFUGsiSZoXmGfA9x?usp=drive_link)

## Keterangan Dataset

Dataset terdiri dari:
- Healthy Cows
- Lumpy Cows
- Non Cows

Dataset tidak disimpan langsung di repository karena ukuran file yang besar.
